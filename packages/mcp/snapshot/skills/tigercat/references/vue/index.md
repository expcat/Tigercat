# Tigercat Vue 3

Vue examples use `v-model`, kebab-case events, and template syntax. Install from `@expcat/tigercat-vue`; import components from PascalCase subpaths for on-demand usage.

查组件用法：先开 [component-index.md](../component-index.md) 定位组件与 PascalCase Package Subpath，再打开 `shared/props/{kebab}.md` 与 `examples/{kebab}.md`（文件内含 `## {Component}`）。Form、Layout 的标题内嵌在同名分类页。跨框架绑定差异见 [shared/patterns/common.md](../shared/patterns/common.md) 与 [shared/glossary.md](../shared/glossary.md)。命令式 API 见 [command-apis.md](../command-apis.md)。
