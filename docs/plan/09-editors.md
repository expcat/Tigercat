# 09 编辑器、画布与打印

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 拖拽过阈值才开始，每个列表使用自己的拖拽会话。
- 打印只含这一张纸。代码编辑器只有一个滚动口，组合输入不回写。富文本按一次操作提交。
- 标注把页面滚动还给页面，方向键把焦点放到形状上。
- 查找替换、结构化文档、文件预览、标注导出和打印预览排在对应优化之后，一次做成。

## 非目标

- 窗口算术不在本篇。T10 O1、O2、O3、O9、O10 与 T10 E6 在 [07](07-virtual.md)。
- 代码编辑器不包含调试器和语言服务器。富文本不包含多人光标。标注不包含自动识别。
- 富文本的消毒边界以 T01 O11 为准，本篇不另写一条 HTML 管道。

## 依赖

- T01 O19 先于 T10 O4。T01 O21 先于 T10 O6。T01 O11 先于 T10 O7。
- T10 O6 的高亮是 token，不把 TRUSTED HTML 留在编辑器里。
- 大文件窗口（T10 E1）调用 07 的测高，不自写一套。
