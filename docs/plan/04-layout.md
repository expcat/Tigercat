# 04 布局

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 卡片只有一个激活面，侧栏按逻辑边排列，分栏停在像素上，缩放改布局盒。
- 滚动区把方向键还给输入控件，轮播位移跟阅读方向一致，列表行的点击面只包住主内容。
- 断点与列数走 W0 的静态媒体查询或容器查询，不再写 `data-tiger-bp` 监听。

## 非目标

- 应用壳的拼装在 [10](10-composite.md) 的 T11 E1。本篇 T06 E2 只提供跳到 `main` 的链接和顶栏开关，并在 W10 与壳一起验收。
- 不把瀑布流做成第二套绝对定位测量，默认保持源顺序（T06 O14、E6）。

## 依赖

- 卡片 href 调用 W2 的 `link-utils`（T02 O1）。T06 O1 整项在 W8 一次做完，包含激活面，不先打一个只改 href 的补丁。
- 轮播方向使用 W0 的方向合同。
- T06 O18 的虚拟行盒与 [07](07-virtual.md) 的窗口一致，不另测一套行高。
