# 08 图表

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 饼图默认正好一圈。甘特的今天来自调用方时钟。折线点序号和柱的类目跟数据键一致。非有限数不把整轴打成 NaN。
- 组织图头像与图表导出里的地址走 W2 的协议门。导出文件只含已经允许的地址。
- 图有名字，系列数据仍能逐条读到。框架层只做绑定，几何留在 core。
- 瀑布图和桑基图是 T09 E13 的两张新图，排进 W9，不另起「以后再做」的清单。

## 非目标

- 关键路径和资源直方图不放进甘特（T09 E11 已写明）。
- 不保留空的 `DonutChart` 别名（T09 O21）。环形是饼的一种表现，随图表重构删除。
- 不把提示做成页面级工具条。

## 依赖

- T09 O3 在 W2，调用 T02 O1 的允许列表，不在 SVG 里自建协议判断。
- T09 O18 使用 T01 O5 的文本规则，并复用 O3 的地址判断。
- T09 O2 与 T08 O2、T11 O19 共用调用方时钟，排在 W6，避免日历、甘特和复合时间各取一次 `Date.now()`。
- 方向只读 W0 的 `dir`（T09 O15）。
