# 06 数据与表格

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 导出走 T01 O5 的一条消毒规则。日历的月份和「今天」用调用方时钟，渲染函数里不取本机当前时间。
- 虚拟表的窗口和滚动口是同一个盒子，固定列叠层和列窗口跟 [07](07-virtual.md) 的公式一致。
- 行键一种身份。选择范围、分组计数和编辑提交以数据源为准。
- 日历、倒计时、时间线、折叠的正确性在本篇一起收，不拆成无人认领的边角。

## 非目标

- 不维持 Table 与 VirtualTable 两套键盘。合成一个组件、虚拟作为一种策略，是 T08 E1，排在窗口对齐之后。
- 不在表内做页面级查询条。那是 T11 E2。

## 依赖

- T08 O1、O2、O3、O4、O5、O16、O22 在 W6，并且 T10 O1、O2 先合入。
- T08 O11 的行键调用 T04 O8 的字符串身份。
- 卡片树水合（T08 O6）在 W8 整项完成：服务端和客户端第一次都输出表格。
