# W9 T08 E1–E16

`VirtualTable` renders `Table` with `virtual`. Fixed-height rows use `getTableVirtualWindow`. Variable height, spans, groups, and expand leave the window. Column virtualization uses `virtualizeMiddleColumns` so pinned columns stay outside the slice. Header filter, multi-sort, grid keyboard, editable cells, summary row, card virtualization, and drag handles are core helpers (`w9-data.ts`) with table props for sorts, column widths, grid, and collapsed groups. Selection copy for this page and loaded rows is in `data-labels.ts`. Remote all only notifies. Shift range skips disabled keys.

Calendar stays one card: fullscreen no longer stretches it. Month view adds a week-number column. Countdown exposes `data-remaining-ratio` and resets when the target changes. Timeline opposite labels, nested collapse keys, and summary stickiness are covered by the core helpers; the timeline and collapse views are not fully rebound in this pass.
