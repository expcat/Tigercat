# W9 T01 E1–E13, OBS-1, OBS-2

Migration notes for the foundation enhancements. Barrels are listed in `w9-t01-exports.txt` and are not edited here.

## E1 Nested theme root

`nearestThemeRoot(node)` walks to the closest `[data-tiger-theme-scope]`. `createTigerThemeScope({ nested: true })` writes only the variables that preset sets (`themeConfigOwnCssVars`). A nested `ConfigProvider` with a `theme` binds that scope on its own element, so parent custom properties stay in place. Overlay portals use the nearest theme root when it is not `documentElement`. An overlay host still wins when one is present.

## E2 Accent scale

`deriveAccentScale(seed, { neutral, radius, density })` builds accent 1–12, neutral 1–12, and shadow 1–6. Radius steps come from one `--tiger-radius` base. The seven named presets call this function through `*ThemeKnobs` / `*ThemeScale`. Their existing semantic color tables are not a second generator.

## E3 Seed states and contrast

`relativeLuminance`, `contrastRatio`, and `assertContrast` live in `utils/contrast.ts`. `deriveInteractionStates(seed)` produces hover, active, disabled, and foreground, and rejects text pairs under 4.5:1 and control boundaries under 3:1. `packages/core/scripts/check-contrast.mjs` runs from `generate-tokens.mjs`. Component tokens that are not in `CONSUMED_COMPONENT_TOKENS` are omitted.

## E4 First paint

`colorSchemeInitScript({ storageKey, nonce, attribute })` returns a blocking `<script>` that sets light, dark, or system on `<html>` from `localStorage` before hydration. Put it in the document head. It does not call `document.write`.

## E5 Tailwind

The plugin maps `surface`, `muted`, `line`, and `rounded-md` to token variables (`tigercatSemanticTheme`). Alert, loading, chart, steps, and workflow keyframes are no longer passed to `addBase`. Those style objects stay on their component modules.

## E6 Parts

`partAttrs(component, part)` and `stateAttrs(state)` are the only cross-framework style contract. `COMPONENT_PARTS` lists part names for Button, Modal, Select, Tabs, and Menu.

## E7 Focus primitives

`createRovingFocus` handles arrow keys, Home, and End, and skips disabled items. `createDismissLayer` dismisses on Escape and outside pointerdown. Escape reaches only the top of a module stack that is separate from `createFocusScope`.

## E8 Forced colors

`packages/core/src/themes/forced-colors.css` (and `forcedColorsCss`) covers `prefers-contrast: more` and `forced-colors: active` with `Canvas`, `CanvasText`, `LinkText`, `Highlight`, and a visible focus outline. The named high-contrast preset remains a semantic delta. The token generator appends this file to `tokens.css`.

## E9 DTCG

`packages/core/tokens/tokens.dtcg.json` is the typed source (`$value` / `$type`). `node packages/core/scripts/emit-tokens.mjs` writes CSS variables and a Figma-like JSON, and refreshes `tokens.json` only when the tree changes. `generate-tokens.mjs` still builds the runtime token module from `tokens.json`.

## E10 Container queries

`containerBreakpointCss()` and the `tigerContainer` class (`container-type: inline-size`) use the same breakpoint names as the tokens: xs, sm, md, lg, xl, 2xl.

## E11 Status channels

`chartStatusChannel(index)` pairs a line style, pattern, and icon. Color still comes from the accent scale. The list length is the chart palette count (6).

## E12 Export exchange

`createExportStream(rows, { chunkSize })` yields chunks without copying the whole sequence. `printExchangeTokens` carries `marginMm` and `pageBreak`. Invalid `chunkSize` throws. The xlsx writer is unchanged.

## E13 Preset review

`reviewPreset(preset)` returns warnings for missing accent steps, radius base, density, or shadow steps. `reviewPreset(defaultTheme)` is empty because the default preset now carries a scale from `deriveAccentScale`.

## OBS-1 Inplace

Display and editing are `toggleInplace` in core. Vue and React render the display slot until editing, then the input slot. Props: `editing`, `defaultEditing`, `onEditingChange`, `disabled`. Enter commits. Escape cancels. Text does not grow an editable mode.

## OBS-2 CopyButton

The button calls `copyTextToClipboard` only. Failure sets `aria-invalid` and status text. Focus stays on the button. Text and Code already call `copyTextToClipboard`; they were not rewritten.
