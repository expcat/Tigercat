## ImagePreview

- 旧的默认行为：工具条只有缩放和旋转，多图在两端停止。
- 3.0 的唯一行为：工具条增加水平翻转、只下载当前图片地址、回到 1:1；多图循环。某一项用 Vue `toolbarItem` 或 React `renderToolbarItem` 替换。替代文本仍在图片上。

## ImageGroup

- 旧的默认行为：灯箱的打开和索引只由组内部持有。
- 3.0 的唯一行为：`open` 与 `currentIndex` 可受控。方向键在组内移动。灯箱地址是当前显示的图，含加载失败后的回退图。

## AvatarGroup

- 旧的默认行为：溢出按钮把折叠的头像展开到组里。
- 3.0 的唯一行为：溢出按钮打开现有浮层，列出被折叠头像的名字。Avatar 上不新增弹层 props。

## QRCode

- 旧的默认行为：固定纠错等级 M，状态只有 active、expired、loading。
- 3.0 的唯一行为：`errorLevel` 为 L、M、Q、H。中心 `icon` 是路径数据或组件，不改矩阵。`status` 包含 `scanned`。

## Code

- 旧的默认行为：代码块没有行号、语言标签和换行开关。
- 3.0 的唯一行为：可选行号、语言标签和换行开关。复制的仍是原始字符串。

## ImageCropper

- 旧的默认行为：比例只来自数值 `aspectRatio`，没有旋转、翻转和圆形遮罩。
- 3.0 的唯一行为：预设 `1:1`、`4:3`、`16:9`、`free`，加上旋转、翻转和圆形遮罩。输出边长仍有上限。CropUpload 仍只选文件和确认。

## ImageCompare

- 旧的默认行为：滑块值文本只有露出比例。
- 3.0 的唯一行为：前后两侧有标题槽。标题进入滑块值文本。页面仍可滚动。

## Watermark

- 旧的默认行为：平铺间距只有 gapX 和 gapY，打印时保留平铺。
- 3.0 的唯一行为：`rowGap`、`density`、`printVisible` 只改 CSS 变量，不重绘平铺。

## Marquee

- 旧的默认行为：没有边缘渐隐。
- 3.0 的唯一行为：可选 `edgeFade`。渐隐不接收点击。不传名字时仍然不是地标。`prefers-reduced-motion` 仍会暂停。

## Gallery

- 旧的默认行为：没有缩略图画廊组件。
- 3.0 的唯一行为：`Gallery` 接收 `{ src, alt }[]`，展示缩略图、当前项和计数，并打开现有 ImagePreview。
