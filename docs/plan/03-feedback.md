# 03 反馈与浮层

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 警报能关上，加载一套，悬停只认指针，对话框的确定等待结果，确认气泡不困住 Tab。
- 命令式 Message / Notification 的宿主在当前树里，并接收请求级 scope。
- 浮层开关、焦点和滚动锁使用 T01 O6 的一个焦点范围。Vue 与 React 不再各写一份 keydown。

## 非目标

- 不把服务端会话或权限推进命令式 API。
- 多层模态、命令式确认框、抽屉推开是增强，做在 O4、O6 和焦点栈已经收口之后，不与修复缠成兼容分支。

## 依赖

- T01 O3 先于 T05 O6。T01 O6 先于 T05 O5。
- 下拉焦点归还（T07 O5）和图片预览（T02 O6）使用同一焦点范围，任务分别在 [05](05-navigation.md) 与 [01](01-foundation.md)。
