# 01 地基与基础组件

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- token、主题、locale、文档属主、栅格、方向、动效各有一处来源，请求之间不共用进程级单例。
- 导出消毒、焦点范围、剪贴板、虚拟测量、富文本写入、二维码格式位、校验、上传队列、拖拽会话、水印、代码 token 先做成 core 原语，组件只调用。
- T02 的链接协议门、基础组件行为和高亮 / 二维码 / 水印在同一篇排期。
- 对比度在 token 生成期卡死，不散落到每个组件工单里刷色。

## 非目标

- 不在本篇实现 CLI 与发布脚本。组件记录的任务行在 [11](11-tooling.md)（T12 O5、O7、O8）。本篇只定载体，避免两篇各做一遍。
- 不把 Tailwind 插件继续当成组件关键帧的仓库。语义工具类是 T01 E5。
- 不另做 headless 模式开关。T01 E6 的 part / state 是样式合同。
- 应用壳、表单字段和图表系列留在各自的篇。

## 依赖

- T01 O2、O3、O4、O13 先于会再撞上 token、SSR 单例、断点和方向的组件。
- T01 O1 与 T12 O1 同一批：主入口不再顶层加载 Tailwind，样式桶只出 class。这一批不挡住表单开工。
- T01 O5 先于表格与图表导出；O6 先于预览、确认气泡和下拉归还焦点；O17 先于表单规则；O19 先于列表拖拽；O21 先于代码块和代码编辑器；O11 先于富文本按次提交。
- T01 O18 与 T04 O12 都改上传控制器：W1 先给出可取消的队列，W4 收成一份列表时保持取消语义，禁止两次互相覆盖。
- T01 O16 先于「扫得出来」和中心图标（T02 E4）。T02 O3 的失败态可以在格式位未改完时先消除渲染期抛错，但图形矩阵以 O16 为准，不留两套编码器。

## 组件记录

公开组件清单扩展现有 `scripts/lib/public-components.mjs`，不并行第二份 schema。

这份模块已经负责类别、slug、框架组件、文档路由和 exports 组装。再另起一份 JSON 生成它，切换期间会同时存在审查里已经指出的多份名单（类别 slug、CLI 手写表、导出基线）。Ant Design 的公开组件集中在 `components/index.ts` 一条导出清单，文档站按组件分页。Element Plus 用同一套组件目录驱动全量注册和按需解析，而不是文档一份、脚手架一份。3.0 在现有模块上补齐组件名、类别、类型入口、包目标、文档路由、测试组和示例路径，由它生成下游。字段怎么长、谁来读，执行时以 T12 O5 与 O7 为准。
