# 07 虚拟窗口

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 固定行高的结束下标、按 id 测高、无限滚动的单个在途请求，只有一套实现。
- 表、聊天、树、甘特和长列表改调用这套公式。引用方禁止再写一个结束下标或另一套测高键。

## 非目标

- 不在本篇重写编辑器、打印和标注。那些在 [09](09-editors.md)。
- 横向和网格是 T10 E6，做在 O1–O3 收口之后，仍只有一个窗口函数。

## 依赖

- 表头测量与 T01 O10 对齐：高度从 DOM 读，拒绝 NaN 和非正行高。
- T10 O1、O2 先于 T08 O4 和 T11 O2。T10 O3 先于 T11 E3 的「下一页」。
- 拖拽会话是 T01 O19，不在虚拟列表里用模块级 `activeDrag`。
