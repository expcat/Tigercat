# 02 表单

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 必填是规则，一次触发，一次提交，单选与空值一份数据，规则拼成一份再校验。
- 复杂控件的历法、时间、颜色、Cron、空值、键身份、树的半选、上传列表、签名和级联路径跟引擎用同一套读写。
- 键只收成一种字符串身份再比较。树、穿梭、级联、看板列、评论和表行都调用这一处，不各写 `===`。
- Schema 与向导只消费这里的规则，它们自己的任务在 [10](10-composite.md)。

## 非目标

- 不在控件内做第二套级联、TreeTransfer、调度器或组件内选人目录。
- 不把周、月、季、年做成另一个日期组件；那是 T04 E1，做在收口后的 DatePicker 上。
- 数字键盘、提及、上传目录是本篇增强，不提前塞进 P0 的半成品分支。

## 依赖

- T01 O17 的数值比较和路径拒绝先于 T03 的规则引擎。
- T03 O1–O9 先于 T04 O7（复杂控件的空）和 T11 O10–O12。
- T04 O15 与 T07 O8 同一批改 `tree-utils`：搜索零命中就是空列表。
- T04 O23 使用 [07](07-virtual.md) 的窗口，不自写 scrollTop 公式，排在 W6。
- T04 O12 保持 T01 O18 的取消语义。
- 滑块方向读 W0 冻结的 `dir` 合同（T03 O20），不自造物理左右。
