# 05 导航

彻底重构，禁止补丁。条目一次做到新结构：不留弃用别名、双写 prop、运行时兼容分支，或只改半边行为的收尾。每个改到的组件，同一批同步 `skills/tigercat` 与 `examples`。测试只在本地跑，不写入 CI / workflow。

## 目标

- 锚点、面包屑、菜单和导航链接的地址走同一允许列表。
- 菜单一个 Tab 停靠点，下拉把焦点还回去，上下文菜单位置不进带变换的容器，页签只有一颗关闭按钮。
- 树搜索零命中为空列表，虚拟树的滚动容器退出 Tab 序。勾选和拖拽会话跟表单树、core 拖拽原语是同一套。

## 非目标

- 不新做第二套 Menu。弹出菜单共用一套项（T07 E1）是增强，不是平行组件。
- 聚光灯的全局热键默认关闭；最近使用是 T07 E12，不在热键修复里顺手加缓存分支。

## 依赖

- T07 O1 在 W2，且晚于 T02 O1 把允许列表放进 `link-utils`。
- T07 O8、O18、O23 与 T04 的树同一批（W4）：零命中、勾选只说一次、拖拽容器按实例生成。
- T07 O5 使用 T01 O6。T07 O12 使用 W0 的方向合同。
